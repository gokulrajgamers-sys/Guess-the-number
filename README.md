# Guess The Number Game

A simple Python command-line game where you try to guess a random number between 1 and 100.

## Game Features

- 🎮 **10 Attempts**: You get 10 tries to guess the correct number
- 💡 **Hints**: The game provides feedback - "higher" or "lower" than your guess
- 🔄 **Replay**: Play multiple rounds without restarting the program
- 🎯 **Special Messages**: Get encouraging messages based on your performance

## How to Play

1. Run the game:
   ```bash
   python guess_the_number.py

   Game Messages
Correct in 1 try: "Must be your luck found it in one try" 🍀
